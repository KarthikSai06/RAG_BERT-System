# Domain-Specific RAG Helpdesk System

A production-grade Retrieval-Augmented Generation (RAG) pipeline for institutional helpdesk question answering. Designed for a college or university setting, the system answers queries about admissions, fees, examinations, hostel, and scholarship policies strictly from the institution's own document corpus. A BERT-based domain guardrail intercepts out-of-scope queries before they reach the language model, preventing hallucinated responses.

---

## Architecture

```
User Query
    |
    v
[Stage 1] BERT Classifier  -->  Out-of-Domain?  -->  Fixed Fallback Response
    |
    | (in-domain)
    v
[Stage 2] Sentence-BERT + FAISS Retrieval (top-k passages)
    |
    v
[Stage 3] 4-bit Quantized Mistral-7B-Instruct (context-grounded generation)
    |
    v
[Stage 4] Answer + Source Passages displayed in Streamlit UI
```

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Add institutional documents

Place your `.txt`, `.pdf`, or `.docx` files in `data/raw_docs/`. Sample documents are included.

### 3. Run pipeline setup

```bash
python setup.py
```

This runs the following steps in sequence:

```bash
python src/ingest.py                  # Chunk documents
python src/generate_synthetic_data.py # Create BERT training queries
python src/train_classifier.py        # Fine-tune BERT classifier
python src/indexer.py                 # Build FAISS vector index
```

### 4. Launch the interface

```bash
streamlit run app.py
```

If model weights are not downloaded yet, the application still starts in
lightweight mode: domain classification uses a conservative keyword guard,
retrieval uses the generated chunks, and answers quote the best matching
passage. Install the dependencies and run the setup commands to enable the
BERT, Sentence-BERT/FAISS, and Mistral stages.

The app does not download the 7B Mistral model by default because it requires
substantial storage and memory, especially on CPU-only machines. To enable it
explicitly, set `RAG_ENABLE_LLM=1` before launching Streamlit.

### 5. Google Colab

Open `notebooks/colab_runner.ipynb` and run all cells. A public URL will be printed via localtunnel.

## Tech Stack

| Component        | Library / Model                          |
|------------------|------------------------------------------|
| Query Classifier | transformers, bert-base-uncased          |
| Embeddings       | sentence-transformers, all-MiniLM-L6-v2  |
| Vector Index     | faiss-cpu, IndexFlatIP                   |
| LLM Generator    | transformers, bitsandbytes (4-bit NF4)   |
| LLM Model        | mistralai/Mistral-7B-Instruct-v0.2       |
| Web Interface    | streamlit                                |
| Document Parsing | pdfplumber, python-docx                  |

## Evaluation (Phase 2)

The following metrics will be measured in the next implementation phase:

- Retrieval: Recall@k, Mean Reciprocal Rank (MRR)
- Classifier: Accuracy, Macro F1 across 3 classes
- Generation: RAGAS Faithfulness, RAGAS Answer Relevance
- End-to-end: Hallucination rate compared against a plain LLM baseline and a guardrail-free RAG baseline
