# Domain-Specific RAG Helpdesk (BERT + FAISS + Quantized LLM)

A production-grade **Retrieval-Augmented Generation (RAG)** pipeline for institutional helpdesk Q&A — built for a college setting (fees, admissions, exams, hostel). Features a BERT-based domain guardrail that blocks out-of-scope queries before they ever reach the LLM.

---

## Architecture

```
User Query
    │
    ▼
[Stage 1] BERT Classifier ──► Out-of-Domain? ──► Fixed Fallback
    │ In-domain
    ▼
[Stage 2] Sentence-BERT + FAISS (top-3 passages)
    │
    ▼
[Stage 3] 4-bit Mistral-7B-Instruct (context-grounded generation)
    │
    ▼
Streamlit Chat UI (answer + source passages shown)
```

## Quick Start

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add your documents
Drop any `.txt` / `.pdf` / `.docx` files into `data/raw_docs/`.
A sample handbook (`sample_handbook.txt`) is already included.

### 3. Run the pipeline setup (in order)
```bash
# Step 1: Chunk documents into FAISS-ready passages
python src/ingest.py

# Step 2: Generate synthetic BERT training data (300 queries)
python src/generate_synthetic_data.py

# Step 3: Fine-tune BERT classifier
python src/train_classifier.py

# Step 4: Build FAISS vector index
python src/indexer.py
```

### 4. Launch the Streamlit UI
```bash
streamlit run app.py
```

### 5. Google Colab
Open `notebooks/colab_runner.ipynb` and run all cells. It installs dependencies, trains BERT, builds the index, and exposes a public Streamlit URL via localtunnel.

## Tech Stack

| Component | Library |
|-----------|---------|
| BERT Classifier | `transformers` (bert-base-uncased) |
| Embeddings | `sentence-transformers` (all-MiniLM-L6-v2) |
| Vector Search | `faiss-cpu` |
| LLM Generator | `transformers` + `bitsandbytes` (Mistral-7B-Instruct, 4-bit) |
| UI | `streamlit` |
